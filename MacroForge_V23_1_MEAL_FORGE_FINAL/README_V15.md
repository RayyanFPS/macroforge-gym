# MacroForge V15 — Pakistani Food + Global Search + Optional Creatine Lab

## Changes
- Expanded curated Pakistani and English food library, including raita, daal variants, pulao, kebabs, burgers, sandwiches, fruits, staples and more.
- Added generic whey protein, casein and mass-gainer flavor references. Product labels remain authoritative because branded formulas vary by product/flavor.
- Meal Coach suggestions are now built from foods that exist in the Food Log library and can be logged as components directly.
- Global search now merges local curated foods with USDA FoodData Central and Open Food Facts sources, with tolerant token matching and local fallback for common generic foods.
- Added optional Creatine Lab tab with enable/disable, maintenance tracking, optional loading protocol, daily logs, monthly calendar, yearly totals and evidence notes.
- Creatine reference science uses common 5–7 day loading / 3–5 g maintenance protocols from ISSN and NIH ODS. Loading is optional.

## Sources used for science/search implementation
- NIH ODS Exercise and Athletic Performance fact sheet: https://ods.od.nih.gov/factsheets/ExerciseAndAthleticPerformance-HealthProfessional/
- ISSN creatine position stand: https://pmc.ncbi.nlm.nih.gov/articles/PMC5469049/
- USDA FoodData Central API guide: https://fdc.nal.usda.gov/api-guide/
- Open Food Facts API documentation: https://openfoodfacts.github.io/documentation/docs/Product-Opener/v2/search/get-search/
