# MacroForge V23.1 — Meal Forge

This build keeps the existing MacroForge food/training system and adds an original in-app **Meal Forge** section.

Included:
- Pakistani-first + global recipe discovery
- In-app recipe search by name, ingredient, cuisine and tags
- Macro filters (minimum protein / maximum calories)
- Deterministic "Match my remaining macros" ranking based on the user's live daily totals
- Recipe detail view with ingredients, macros, time, servings and method
- Portion-aware recipe data model ready for future scaling
- One-tap meal logging
- 7-day meal planner
- Aggregated smart shopping list from planned meals
- Saved recipes
- Cook Mode with step-by-step navigation
- Mobile-responsive UI
- No external AI/API required for Meal Forge

Design direction is intentionally original: it borrows common meal-planning concepts such as weekly planning, ingredient search, collections, shopping lists and nutrition display, but does not copy Mob's branding or UI.

Important:
- Recipe macro values in this module are curated demo/library values, not laboratory measurements.
- Existing MacroForge food-library data was left untouched in this feature patch.
