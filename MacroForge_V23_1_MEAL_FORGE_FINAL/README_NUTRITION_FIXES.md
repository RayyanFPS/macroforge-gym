# MacroForge — Nutrition & Portion Fix

## What was fixed

- Fixed the catastrophic serving multiplier bug that could turn 240 kcal into 24,000 kcal.
- Named servings such as plates/bowls/pieces now convert through a physical portion weight before calculating nutrition.
- Grams, ml, plates, bowls, cups, wraps, pieces and servings can be entered as numeric amounts.
- Nutrition preview recalculates immediately while typing.
- Curated Pakistani dishes use source-anchored standardized reference values where a published analysis was available.
- Mutton Karahi, Aloo Gosht, Chicken Karahi, Biryani and Haleem were updated from the 2019 University of Agriculture Peshawar study, which reports proximate composition and energy per 100 g of standardized recipes.
- Added separate entries for Aloo, cooked Mutton/Gosht, and combined Aloo Gosht.
- Added gym nutrition entries for whey protein, whey isolate, creatine monohydrate, creatine HCl, a whey+water protein shake reference, and a generic mass-gainer reference.
- Creatine monohydrate is listed as 0 kcal / 0 protein / 0 carbs / 0 fat per 5 g serving based on the cited product label.
- Generic mass-gainer nutrition is explicitly marked as a reference only because mass-gainer formulas vary by brand.

## Accuracy note

There is no single universal “exact” nutrition value for homemade Pakistani dishes. Oil, meat-to-gravy ratio, recipe, cooking loss and serving weight change the result. Source-anchored entries therefore represent the cited standardized recipe, not every possible home or restaurant version.

For packaged foods, the global search should use the product's database nutrition record; users should prefer the exact branded product/label when available.
