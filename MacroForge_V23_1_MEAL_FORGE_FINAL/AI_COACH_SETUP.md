# MacroForge V18.2 AI Coach

This build uses the original limited built-in Coach questions.

The free-form/custom AI Coach backend from V18.1 has been removed.

## Requirements

- No Node.js
- No npm
- No npx
- No OpenAI API key
- No local AI server

## Coach questions

- Warm-up
- Progressive overload
- Pre-workout food
- Protein
- Beginner plan

Answers use the user's current MacroForge plan where relevant and are generated locally in the browser.
