# MacroForge V17

V17 is a dynamic feature layer on top of V16.2.

## Major additions
- Robust Meal Coach with event-delegated "Log this meal" action; each component is logged individually from the Food Log library.
- Daily macro reminders and responsive desktop/mobile in-app popups.
- Warning-only macro alerts when protein/carbs/fat exceed their targets by more than 10 g.
- Separate live Cardio Lab with start/end timer and automatic logging when the planned duration is reached.
- Cardio history and estimated calorie expenditure using MET-based estimates.
- Separate Workout Splits page with recommendations and explanations.
- Separate offline Forge Coach page for contextual training/nutrition questions.
- BMI screening with an under-18 safeguard that avoids adult BMI cutoffs.
- Beginner science foundations: maintenance, bulk, cut, protein, carbs, fat, muscle growth, form and ego lifting.
- Training Lab exercise browser with 150+ movements and public YouTube form-search links; no copyrighted video is copied into the app.
- 25 rotating bodybuilding/training tips, 10 seconds each.
- Macro/workout/cardio/water streaks.
- Expanded exercise record selector.

## Notes
- The Coach is an offline rule-based assistant, not a cloud LLM and not a medical diagnostic service.
- BMI is a screening measure; adult BMI categories are not used for users under 18.
- Cardio calorie values are estimates, not measurements.
- Pakistani dish nutrition remains a reference estimate because recipe and oil amounts vary.
